# 搜索问题库

按出行场景选用搜索问题模板。所有搜索统一带当前月份/年份，避免搜到过期攻略。

## 城市亲子游（带学龄儿童）

- `{城市} 亲子游 攻略 {月份}`
- `{城市} 适合孩子 景点 博物馆/科技馆/动物园`
- `{景点} 门票 预约 儿童票`
- `{城市} 地铁/公交 亲子 出行`
- `{城市} 暑期/节假日 人多吗 避坑`

## 信息核验清单（关键信息必须溯源）

| 信息类型 | 核验方式 | 为什么 |
|---|---|---|
| 门票价格/开放时间 | 景区官网/官方公众号/OTA 当日页 | 节假日调价频繁 |
| 预约/限流要求 | 官方预约平台/公告 | 没预约可能白跑 |
| 交通班次/时刻 | 12306/航司/客运官网 | 班次季节调整 |
| 天气 | 权威天气源（出发前 3 天再复核） | 决定备选方案 |
| 特殊政策 | 政府/景区公告、权威新闻 | 管制/关闭信息 |
