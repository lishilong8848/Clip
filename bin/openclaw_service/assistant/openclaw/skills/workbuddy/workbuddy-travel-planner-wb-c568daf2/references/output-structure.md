# 输出结构模板

方案交付时按以下结构组织。灵活调整小节顺序，但七部分齐全。

## 1. 方案摘要

```
# {目的地}旅游规划方案

- 时间：{出发日期} - {返回日期}（{X天Y晚}）
- 同行人：{结构描述}
- 预算：约 {金额}（{档位说明}）
- 总览：{一句话方案说明，如"以{主景点}为核心、住在{区域}、节奏{紧凑/休闲}"}
- 信息基准日：{YYYY-MM-DD}（行程信息均基于此日检索结果，出发前请复核）
```

## 2. 目的地调研

每个板块给出要点 + 来源标注：

- 必去清单（3-5 个，标注为什么值得去 + 适合同行人吗）
- 门票与预约要求（表格：景点 / 票价 / 儿童老人优惠 / 预约方式 / 开放时间，来源+日期）
- 交通方式（到达 + 市内）
- 住宿区域建议（2-3 个区域，各写优劣）

## 3. 天气研判

```
### 天气研判（信息日期：{YYYY-MM-DD}）

**规划期气候**：{该季节气温区间、降水特点、注意事项，来源}

**出发前逐日预报**（出发前 3 天复核）：

| 日期 | 天气 | 温度 | 穿衣建议 | 对行程的影响 |
|---|---|---|---|---|
| {日期} | {晴/雨...} | {区间} | {建议} | {如"第2天有雨→上午改室内备选"} |
```

实时天气与规划期气候冲突时，以实时为准并主动调整行程。

## 4. 逐日行程

每天一个小节：

```
### 第 X 天（周X）{日期}：{当日主题}

- 上午：{地点}（{时间安排}）
- 中午：{用餐安排}
- 下午：{地点}（{时间安排}）
- 晚间：{安排}
- 备选：{天气/预约失败时的替代方案}
- 当日提醒：{预约/证件/时间点}
```

## 5. 路线图

```
### 路线图

**整体到达**：{出发地→目的地交通方案，时长、换乘、费用区间；自驾注明高速与里程}

**每日动线**：
- D1：{起点} →（{交通方式}，{耗时}）→ {节点} →（{交通方式}，{耗时}）→ {节点}
- D2：……

**路线示意图**：route.png（用 scripts/route_map.py 生成，可选）
```

## 7. 实用清单

- 预约提醒（景点/票种/提前天数/放票时间）
- 行前准备（证件/衣物/药品/孩子用品/充电）
- 避坑提示（按搜索结果整理，标注来源）
