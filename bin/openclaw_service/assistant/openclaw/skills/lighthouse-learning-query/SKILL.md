# 灯塔学练与题库查询

> 本说明不是实时数据，也不授予权限。工具返回名为准，OpenClaw 展示可能带 `lighthouse_` 前缀。

## 适用场景
只读查询获准的笔试/值班/专业工程师题库与资料，通过未完成工作查询今日题单发布及答题进度。错题、笔记和质疑内容仅在已有只读入口提供时查询，不声称读取了未接入内容。

## 查询口径
- 学练**全部只查询**；今日未发布题单与已发布但未完成分开说明。
- 题库范围为原权限：管理员完整题库，值班账号仅原本可见题目及已开放答案；缺失答案不代表题库无答案。
- 题库检索理解语义后提取 2-6 个核心术语/同义/缩写，以空格分隔放入 `search`；`bank` 为 written/duty/professional，未指定则省略。

## discover 原生 API / 专用 tool
- 题库查询使用 `GET /api/assistant/question-bank`，返回题干、选项和获准答案；`search` 是候选召回，不当作已确认事实。原学练页面的接口不自动成为助手工具，以当前 discover 返回的只读接口为准。
- 题目返回 `materials` 时用 `GET /api/assistant/question-material` 读文字，`material_id` 只取已有 id，`offset` 从 0 起、`length` ≤ 6000，按 `next_offset` 继续。
- 查询用 `query(operation={api_id, params})`，api_id 从 discover 返回中选取；不把带 `…` 的占位当 id。

## 记录 ID 与字段
- 题目用返回的题目 id/版本，资料用 `material_id`；图片通过文字识别读取，不能据此虚构图形关系。
- 检索不到可靠候选可换一次同义词，不得编造内容或绕过未开放答案。

## 质疑附件
- 质疑附件按其**实际注册的只读接口与当前账号权限**读取；若没有只读入口则明确说明“无法读取”，不凭空编造内容，也不绕过权限。

## 办理顺序/确认/超时
- 题目查询 → 读资料文字 → 结合题干核对，引用真正相关原题；文件/识别失败时保留说明，不认为答案为空。
- 超时/缓存未就绪时说明未知，不当作零条或无答案。
- 通用知识与题库依据分开表述，题库说明不等于现场状态。

## 权限与禁止边界
- 答题、答案提示、质疑提交、发布、编辑及设置均在原学练页面办理，不在助手准备或提交。
- 范围沿用原权限，不得扩大；未开放答案不猜测。

## 调用例子
`discover(keyword="题库")` → `query(operation={api_id:"GET /api/assistant/question-bank", params:{search:"UPS 不间断电源", bank:"written"}})` → 命中题目返回 materials 时读资料核对。
